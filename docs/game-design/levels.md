# Сюжетные главы и финансовые уровни

Структура игры состоит из **6 глав (6 игровых дней, 18 практических заданий — строго по 3 задания в
день)**,
объединенных сквозным сюжетом и математическим балансом. Все события следуют правилу «Дом как
постоянный хаб»
(начинаем утро, ночуем и подводим итоги всегда дома).

Для реализации в сжатые сроки (1 неделя) все активности сведены к **4 типовым переиспользуемым
UI-шаблонам** в соответствии с требованием ТЗ п. 2.5.14 (*«Новое задание добавляется без переработки
основной логики приложения»*).

### Правило смены суток (TimeOfDay)

* Каждый игровой день (глава) содержит ровно **3 солнечных жетона времени**:
    * ☀️ **Утро (жетон 1/3)** — Задание 1
    * ⛅ **День (жетон 2/3)** — Задание 2
    * 🌙 **Вечер (жетон 3/3)** — Задание 3
* **Расход времени:** Тратят время **только финансовые задания** (1 задание = ровно 1 жетон).
  Бытовые действия (кормление питомца, покупка еды в магазине, пополнение или снятие из копилки,
  гардероб) расходуют **0 жетонов времени**.
* После выполнения 3-го задания наступает **💤 Ночь**: открывается экран «Итоги дня», начисляется
  пассивный процент копилки, и по кнопке «Уложить питомца спать» день безопасно завершается.
