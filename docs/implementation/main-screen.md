# Спецификация основного экрана («Дом Финни» / Main Screen)

Данный документ описывает структуру, компоненты, модель состояния и пользовательские взаимодействия **Основного экрана приложения «Питомец Финни»** в соответствии с [ТЗ (п. 2.5.3)](../game-design/TZ.md#253-главный-экран), [Геймдизайн-спецификацией](../game-design/AGENTS.md) и архитектурными стандартами [`docs/core/`](../core/).

---

## 1. Назначение и соответствие ТЗ

Согласно **ТЗ п. 2.5.3**, главный экран является центральным узлом приложения:
> *«Питомец, доступный баланс, сумма накоплений, текущая цель, основные показатели состояния и активное задание видны одновременно, без сложной навигации.*  
> *С главного экрана доступны план личного бюджета, задания, покупки, накопления, прогресс и раздел для взрослого.»*

Экран спроектирован так, чтобы ребенок 7–11 лет в любой момент времени:
1. Видел своего питомца и его эмоциональное и физическое состояние;
2. Понимал, сколько у него свободных денег в кошельке и сколько отложено на заветную мечту;
3. Знал, какое задание доступно прямо сейчас и сколько энергии дня (солнечных жетонов) осталось;
4. Мог в один тап переключиться в нужный раздел нижнего меню: **Задачи**, **Копилка**, **Магазин** или **Уровни**.

---

## 2. Анатомия и компоновка экрана

Основной экран состоит из трех визуальных ярусов:
1. **Верхний игровой HUD (Статус-бар):** постоянные метрики состояния, кошелька и времени;
2. **Центральная динамическая сцена (Хаб / Контент активного раздела):** интерактивная комната питомца либо контент выбранной вкладки;
3. **Нижнее навигационное меню (`GameBottomBar`):** 4 ключевых раздела с 3D-эффектом активной вкладки.

### 3.1. Верхний игровой статус-бар (HUD)

Реализован на базе готовых компонентов из [`shared/.../core/ui/components/game/`](file:///home/denis/AndroidStudioProjects/Finni/shared/src/commonMain/kotlin/com/hackathon/finni/core/ui/components/game/):

| Элемент | Компонент | Значения | Поведение и интерактивность |
| :--- | :--- | :--- | :--- |
| **Датчик сытости с миской** | `HungerRadialGauge` | `0 .. 5` делений | Индикатор обязательных расходов («Надо»). Падает на 2 деления каждое Утро. Нажатие на миску открывает быстрое кормление или вкладку «Магазин $\rightarrow$ Еда». При 0 миска подсвечивается, питомец урчит в животе. |
| **Медальон настроения** | `MoodIndicatorBadge` | `Sad`, `Neutral`, `Happy` | Эмоциональный отклик на финансовые решения («Хочу»). При тапе питомец произносит реплику с причиной своего настроения (*«Мне грустно, потому что я голоден»* или *«Я счастлив: мы отложили монеты на телескоп!»*). |
| **Бейдж баланса кошелька** | `GameCoinBadge` | Число монет (например, `120 🪙`) | Операционный счет для карманных денег и повседневных трат. Тап открывает историю доходов/расходов за текущий день. |
| **Индикатор времени суток** | `TimeOfDayBadge` | `Morning`, `Day`, `Evening` + `1..3` жетона | Ограничитель темпа дня. Утро = планирование и завтрак; День = задания и покупки (тратят по 1 жетону); Вечер = жетоны исчерпаны, доступен переход ко сну и итогам дня. |
| **Кнопка настроек** | `GameIconButton` | Иконка `ic_game_gear` | Открывает модальный математический пример `ParentGateModal` для входа в защищенный раздел взрослого. |

### 3.2. Центральная интерактивная сцена («Комната Финни»)

Центральная часть экрана отображает уютную комнату персонажа с динамическим фоном, меняющимся в зависимости от фазы времени суток (`Morning` $\rightarrow$ нежно-голубой утренний свет; `Day` $\rightarrow$ яркий солнечный день; `Evening` $\rightarrow$ теплый закатный уют; `Night` $\rightarrow$ колыбельный индиго).

#### Составляющие комнаты:
1. **Интерактивный питомец Финни:**
   - Анимированный персонаж с реакциями на касания (мурчание, помахивание лапкой, прыжок);
   - Речевой пузырь (диалоговое облачко) с контекстными подсказками и педагогической обратной связью;
   - Косметические предметы, купленные ребенком в магазине (шапочка, бантик, коврик).

2. **Проекция «Копилки мечты» (Визуализация цели):**
   - В углу комнаты отображается полупрозрачный силуэт выбранной цели (Телескоп, Набор красок, Мяч);
   - По мере пополнения копилки предмет физически раскрашивается снизу вверх (ТЗ п. 2.5.7);
   - Нажатие на силуэт мгновенно переключает экран на вкладку **«Копилка»**.

3. **Виджет активного задания / Квеста дня:**
   - Расположен в нижней трети комнаты;
   - Показывает текущую сюжетную задачу главы, сумму награды (`+20..+40 🪙`) и кнопку быстрого запуска;
   - Если день завершен или жетоны исчерпаны, виджет трансформируется в кнопку **«Уложить Финни спать 🌙»**.

### 3.3. Разделы нижнего меню (`GameBottomBar`)

Панель высотой `76.dp` с глянцевым янтарным градиентом и 3D-выпуклой анимацией активной вкладки.

#### 1. Вкладка «Задачи» (`GameTab.Tasks`)
* **Главный вид:** Описанная выше интерактивная комната питомца + список доступных заданий текущей главы:
  * Задание 1: Сюжетная дилемма (`DILEMMA`);
  * Задание 2: Сортировка расходов или честного труда (`CARD_SORTING`);
  * Задание 3: Умный шопинг (`SMART_SHOP`).
* Пройденные задания помечаются золотой звездой; активное задание выделено пульсирующей рамкой.

#### 2. Вкладка «Копилка» (`GameTab.Piggy`)
* **Экран целевых сбережений:**
  * **Карточка текущей цели:** Название предмета (например, *«Астрономический телескоп»*), целевая сумма (`200 🪙`), текущий прогресс (`110 🪙`) и процент выполнения (`55%`);
  * **Визуальная шкала:** Большая анимированная копилка-свинка или сейф;
  * **Панель пополнения:** Быстрые кнопки перевода монет из кошелька в копилку:
    * `+10 🪙`
    * `+25 🪙`
    * `Вся сдача (оставить ровно 20 на еду)`
  * **Защищенная кнопка «Забрать из копилки»:** Срабатывает только после показа модального диалога `ConfirmSavingsWithdrawal` с предупреждением: *«Если забрать монеты, Телескоп отдалится на 2 дня!»*;
  * **Блок пассивного процента:** *«Копилка растет! +5% каждые 3 дня без снятий. До бонуса остался 1 день!»*.

#### 3. Вкладка «Магазин» (`GameTab.Shop`)
* **Витрина покупок с разделением на две категории (ТЗ п. 2.5.6):**
  * **Переключатель фильтра:** `Обязательное (Еда и уход)` | `Желания (Игрушки и уют)`;
  * **Каталог товаров (сетка карточек):**
    * *«Сытный завтрак»* (10 монет, +2 сытости);
    * *«Витаминное яблоко»* (5 монет, +1 сытости);
    * *«Заводная мышка»* (25 монет, +1 счастья);
    * *«Космический постер»* (40 монет, украшение стены комнаты).
  * **Карточка товара:** Фото, цена, влияние на шкалы питомца, кнопка «Осмотреть» и кнопка «Купить»;
  * **Защита от овердрафта:** При нехватке монет кнопка «Купить» блокируется с подсказкой, сколько именно монет не хватает и как их заработать.

#### 4. Вкладка «Уровни» (`GameTab.Levels`)
* **Интерактивная карта 6 глав истории:**
  * Дорожка из 6 сюжетных локаций с флажками и замочками:
    1. *Глава 1: Новая комната (Основы бюджета);*
    2. *Глава 2: Умный покупатель (Шопинг и качество);*
    3. *Глава 3: Друзья и здоровье (Ценности vs Вещи);*
    4. *Глава 4: Яркие ловушки (Реклама и азарт);*
    5. *Глава 5: Планы меняются (Подушка безопасности);*
    6. *Глава 6: Большая ярмарка (Триумф и финал).*
  * Клик по открытой главе показывает список ее 3 игровых дней, финансовые инсайты и статистику сбережений;
  * В правом верхнем углу — кнопка **«Финансовый словарик»** с детскими иллюстрированными карточками понятий.

## 4. Модель состояния экрана (`MainUiState`)

В соответствии с паттерном **Immutable StateFlow** ([`docs/core/viewmodel-layer.md`](../core/viewmodel-layer.md)):

```kotlin
data class MainUiState(
    // Выбранная вкладка
    val selectedTab: GameTab = GameTab.Tasks,

    // Метрики питомца (HUD)
    val petName: String = "Финни",
    val hunger: Int = 4,              // 0..5
    val mood: PetMood = PetMood.Happy, // Sad, Neutral, Happy
    val walletCoins: Int = 70,        // Операционный кошелек
    val timePhase: GameTimePhase = GameTimePhase.Morning, // Morning, Day, Evening
    val dayTokensLeft: Int = 3,       // 0..3

    // Копилка мечты
    val savingsGoal: SavingsGoalUiModel = SavingsGoalUiModel(
        title = "Астрономический телескоп",
        targetAmount = 200,
        currentAmount = 110,
        iconResName = "img_telescope"
    ),

    // Активное сюжетное задание
    val activeTask: ActiveTaskUiModel? = ActiveTaskUiModel(
        id = 2,
        title = "Первые конверты",
        reward = 30,
        requiredEnergyTokens = 1,
        templateType = TaskTemplateType.BUDGET_SPLIT
    ),

    // Текущий сюжетный прогресс
    val currentChapterId: Int = 1,
    val currentDayInChapter: Int = 1,

    // Загрузка и фоновые процессы
    val isLoading: Boolean = false
)
```

## 5. Пользовательские действия (`MainViewModel`)

ViewModel наследует делегаты согласно [`docs/core/viewmodel-delegates.md`](../core/viewmodel-delegates.md):

```kotlin
class MainViewModel(
    private val router: Router,
    private val petRepository: PetRepository,
    private val economyRepository: EconomyRepository,
    private val tasksRepository: TasksRepository,
    private val errorHandler: ErrorHandler,
    private val refreshHandler: RefreshHandler,
    private val eventHandler: EventHandler
) : ViewModel(),
    ErrorHandler by errorHandler,
    RefreshHandler by refreshHandler {

    private val _uiState = MutableStateFlow(MainUiState())
    val uiState: StateFlow<MainUiState> = _uiState.asStateFlow()

    // 1. Переключение нижних вкладок
    fun onTabSelected(tab: GameTab) {
        _uiState.update { it.copy(selectedTab = tab) }
    }

    // 2. Взаимодействие с питомцем и миской
    fun onBowlClick() {
        if (_uiState.value.hunger < 5) {
            // Если в кошельке есть монеты на корм (10 монет)
            launchSafe {
                petRepository.feedPet(cost = 10)
                _uiState.update { it.copy(hunger = it.hunger + 1, walletCoins = it.walletCoins - 10) }
                eventHandler.sendEvent(UIEvent.Toast(UiText.Dynamic("Финни вкусно поел! +1 к сытости 🍲")))
                Unit.right()
            }
        } else {
            eventHandler.sendEvent(UIEvent.Toast(UiText.Dynamic("Финни уже сыт и готов к игре!")))
        }
    }

    fun onPetClick() {
        // Воспроизведение случайной анимации / реплики
        val speech = when (_uiState.value.mood) {
            PetMood.Happy -> "Я так рад, что мы копим на телескоп!"
            PetMood.Neutral -> "Что мы будем делать сегодня?"
            PetMood.Sad -> "В животе урчит, давай подкрепимся..."
        }
        eventHandler.sendEvent(UIEvent.Toast(UiText.Dynamic(speech)))
    }

    // 3. Запуск активного задания
    fun onStartActiveTaskClick() {
        val task = _uiState.value.activeTask ?: return
        if (_uiState.value.dayTokensLeft <= 0) {
            eventHandler.sendEvent(UIEvent.Toast(UiText.Dynamic("Солнечные жетоны закончились! Пора отдыхать 🌙")))
            return
        }
        router.push(TaskRunner(taskId = task.id, templateType = task.templateType))
    }

    // 4. Пополнение копилки мечты
    fun onDepositToSavings(amount: Int) {
        val available = _uiState.value.walletCoins
        if (amount > available) {
            eventHandler.sendEvent(UIEvent.Toast(UiText.Dynamic("Недостаточно монет в кошельке!")))
            return
        }
        launchSafe {
            economyRepository.transferToSavings(amount)
            _uiState.update { current ->
                val updatedGoal = current.savingsGoal.copy(
                    currentAmount = current.savingsGoal.currentAmount + amount
                )
                current.copy(
                    walletCoins = current.walletCoins - amount,
                    savingsGoal = updatedGoal,
                    mood = PetMood.Happy
                )
            }
            eventHandler.sendEvent(UIEvent.Toast(UiText.Dynamic("В копилку добавлено $amount 🪙! Мечта всё ближе!")))
            Unit.right()
        }
    }

    // 5. Запрос на снятие средств с копилки
    fun onWithdrawFromSavingsClick() {
        val goal = _uiState.value.savingsGoal
        // Открываем модальное окно подтверждения с расчетом отдаления цели
        router.push(
            ConfirmSavingsWithdrawal(
                goalTitle = goal.title,
                amount = 20,
                delayDays = 2
            )
        )
    }

    // 6. Покупка в магазине
    fun onBuyShopItem(item: ShopItem) {
        if (_uiState.value.walletCoins < item.price) {
            eventHandler.sendEvent(
                UIEvent.Toast(UiText.Dynamic("Не хватает ${item.price - _uiState.value.walletCoins} монет!"))
            )
            return
        }
        launchSafe {
            economyRepository.purchaseItem(item.id)
            _uiState.update { current ->
                current.copy(
                    walletCoins = current.walletCoins - item.price,
                    hunger = (current.hunger + item.hungerBoost).coerceAtMost(5),
                    mood = if (item.isEmotional) PetMood.Happy else current.mood
                )
            }
            eventHandler.sendEvent(UIEvent.Toast(UiText.Dynamic("Куплено: ${item.title}!")))
            Unit.right()
        }
    }

    // 7. Переход к настройкам взрослого
    fun onSettingsClick() {
        router.push(ParentGateModal(onSuccessDestination = ParentZone))
    }

    // 8. Завершение дня / Переход ко сну
    fun onEndDayClick() {
        router.push(
            DailySummary(
                dayNumber = _uiState.value.currentDayInChapter,
                chapterId = _uiState.value.currentChapterId
            )
        )
    }
}
```

## 6. Защита от тупиковых ситуаций (Кризис-менеджмент)

Согласно [разделу 4 Спецификации геймдизайна](../game-design/AGENTS.md#4-разрешение-тупиковых-ситуаций-кейс-0-монет-0-еды-0-жетонов-времени), если у игрока `0 монет`, `0 сытости` и `0 жетонов`:
1. **Кнопка «Аварийная полка»:** Появляется рядом с пустой миской в комнате. Выдает бесплатную овсяную кашу и воду, восполняя сытость до `1`, чтобы питомец взбодрился;
2. **Кнопка «Сон в любое время»:** Даже при 0 жетонов кнопка сна доступна бесплатно. Сон сбрасывает день, восстанавливает 3 жетона и переводит игру на Утро следующего дня.
